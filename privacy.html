Zásady ochrany soukromí

Platnost od 18. září 2026. Provozovatel: Dominik Krampla, kontakt dominikkrampla@gmail.com.

1. Rozsah a získávané údaje

Aplikace agenti je soukromý asistent pro provozovatele a pozvané uživatele. Podle udělených oprávnění zpracovává identifikaci připojeného účtu, e-mailové hlavičky, adresáty, předměty a obsah zpráv, případně vyžádané přílohy; dále názvy a identifikátory kalendářů, časy, popisy, místa a účastníky událostí. Samostatně může zpracovávat přepisy a soubory, které uživatel poskytne. OAuth přístupové a obnovovací tokeny umožňují přístup bez ukládání hesla Google.

2. Účel použití

Údaje slouží výhradně k uživatelem požadovaným funkcím: vyhledávání, shrnutí, identifikaci závazků, návrhům odpovědí a správě kalendářů. Soukromé automatizace mají definovaný rozsah; zprávy a externí pozvánky se odesílají až po schválení uživatelem. Přístup k účtu další osoby vyžaduje její vlastní souhlas a domluvu o tom, kdo smí její data používat.

3. AI služby, předávání a přístup lidí

Vybraný obsah potřebný pro zadaný úkol může být předán nakonfigurovanému poskytovateli AI, například OpenAI, k vytvoření odpovědi. Konkrétní model a poskytovatel závisí na nastavení asistenta; před připojením účtu lze vyžádat jejich aktuální seznam a podmínky uchovávání. Hosting serveru a příslušní poskytovatelé API zpracovávají technické údaje potřebné k provozu. Při používání Telegramu mohou zadané zprávy a doručené výstupy procházet touto platformou. Zpracování může zahrnovat poskytovatele mimo EU/EHP; nelze předpokládat výhradně lokální zpracování.

Provozovatel spravuje server a může mít technický přístup k uloženým údajům a historii asistenta. Aplikace není prezentována jako systém, v němž jsou data ostatních uživatelů před provozovatelem technicky skryta. Přístup dalšího člověka k obsahu Google dat musí být založen na výslovném souhlasu pro konkrétní účel, nebo být nezbytný pro bezpečnost, zákonnou povinnost či jiný případ dovolený pravidly Google.

Google data neprodáváme, nepoužíváme pro reklamu ani k vytváření reklamních profilů. Google Workspace data nepoužíváme k vývoji, zlepšování nebo trénování zobecněných AI či strojově učených modelů. Použití a předávání informací získaných z Google API se řídí Google API Services User Data Policy, včetně požadavků Limited Use. Před povolením zpracování u konkrétního AI poskytovatele musí být jeho nastavení a smluvní podmínky s tímto omezením slučitelné.

4. Ukládání a zabezpečení

Tokeny, vybrané zprávy, přepisy, odvozené poznámky a historie úloh mohou být ukládány na serveru provozovatele; obsah může být součástí pracovních databází a historie konverzací. Nejde nutně jen o dočasné zpracování. Přístup je omezen přístupovými právy; spojení s Google API využívá HTTPS. Žádné zabezpečení není absolutní. Přístupové údaje ani soukromý obsah nepatří do veřejného repozitáře nebo na tento web.

5. Doba uchování, výmaz a odvolání přístupu

Údaje jsou uchovávány po dobu potřebnou pro poskytované funkce a uživatelem požadovanou historii; jednotná automatická lhůta výmazu není pro všechny úložiště nastavena. Uživatel může požádat na kontaktním e-mailu o přehled, opravu či výmaz uložených údajů a odpojení účtu. Provozovatel vyřídí žádost bez zbytečného odkladu; případná zákonná povinnost uchování nebo technická omezení budou vysvětlena.

Přístup lze odvolat také v nastavení propojení Google účtu. Odvolání zabrání dalšímu přístupu přes danou autorizaci, ale samo nevymaže již uložené kopie. Jejich odstranění je třeba výslovně požadovat. Případné kopie u poskytovatelů komunikace a AI se řídí také jejich podmínkami.

6. Tento veřejný web

Tento informační web neobsahuje přihlášení, formuláře, vložené sledovací nástroje ani data připojených účtů. Je hostován na GitHub Pages; GitHub může zpracovávat technické údaje návštěv podle svých zásad soukromí.

7. Změny a kontakt

Při podstatné změně zpracování budou zásady aktualizovány a dotčení uživatelé informováni před rozšířením použití jejich dat. Dotazy a žádosti směřujte na výše uvedený kontakt.
